# Outreach drafts (for Omar to post)

Plan: `docs/plans/seo-geo.md` §6 ("Same facts everywhere", "Mentions on trusted sites"). Drafted
2026-10-20 by the website session. Nothing here is posted automatically: Omar posts each one by hand,
from his own accounts, and edits it to sound like him.

## Rules for every post

- **Help first.** Each draft answers the question fully without the app. The app is mentioned once, at
  the end, with a plain disclosure ("I make this app").
- **Same line everywhere.** Use the shared description word for word where a profile or bio asks for
  one: `CRO Toolbox is a Shopify app to increase average order value (AOV) and lifetime value (LTV).` (`site/src/lib/brand.ts`,
  `docs/listing.md`).
- **Facts from the app's files only.** Prices from `app/lib/plans.ts`: Free; Starter $5.99 a month;
  Growth $19.99; Pro $39.99; yearly $59, $199, $399; 14 day free trial. No invented numbers, results or
  reviews. If a price changes, update these drafts.
- **Links.** Use https://crotoolbox.com (and the Shopify App Store link once the app is live there,
  shown here as `[App Store link]`). Add `?utm_source=<site>&utm_medium=outreach` so Cloudflare Web
  Analytics shows where visits come from.
- **Read each site's rules before posting.** Shopify Community and r/shopify limit self promotion;
  the drafts follow the usual rules (disclose, no link only posts, answer the question), but check
  the current rules on the day.
- After posting, add the link and date to the table below.
