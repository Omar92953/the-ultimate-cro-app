## An order tracking page that cuts support emails and gets the next order

A tracking page has one job first: answer "where is my order?" before the shopper writes to you. Once
it does that well, it can also invite the next order, gently, below the tracking.

**1. What shoppers need first**

- **A lookup without a login:** order number and email.
- **The status in words:** ordered, shipped, out for delivery, delivered. Dates next to each step.
- **Each shipment separately:** carrier, tracking number and a link, so a split order isn't confusing.
- **What's in the order,** with pictures, so they know which parcel is which.
- **Help:** a contact link and the returns page, right there.

**2. How to word a delay**

If a parcel is late, say so plainly, say what you're doing, and say when to contact you. An apology
line for late orders ("Sorry, this order is taking longer than usual") does more than a cheerful
banner.

**3. Then, what can sell**

Below the tracking, never above it:

- **A discount code for the next order,** with a clear expiry.
- **Buy again** for products people reorder.
- **Products that go with what they bought.**
- **After delivery,** a short message asking for a review.

**4. Where to link it**

The main menu or footer, the shipping confirmation email (Settings → Notifications → Shipping
confirmation), and your contact page ("Track your order first").

**5. Measure it**

Watch support messages about order status, and orders placed with the next order code.
