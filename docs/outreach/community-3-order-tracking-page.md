# Shopify Community answer 3: adding a Track your order page

**Where:** https://community.shopify.com, search "track my order page", "order tracking page",
"where is my order". Answer a recent thread without an accepted answer.

**Title (only if starting a thread):** How to add a "Track your order" page to a Shopify store

**Answer:**

Shopify already gives every order a status page with the tracking link once you fulfil it with a
tracking number. Many stores still add a separate "Track your order" page, because shoppers look for it
in the menu or footer instead of searching their inbox.

What that page needs, in order:

1. **A lookup** by order number and email (no login).
2. **The status first**: ordered, shipped, out for delivery, delivered, with dates.
3. **The carrier and a tracking link** for each shipment, so split shipments are clear.
4. **What's in the order**, with product pictures.
5. **What to do if something is wrong**: a contact link or the returns page.

Then link it from the main menu or footer (Online Store → Navigation) and from your shipping
confirmation email (Settings → Notifications → Shipping confirmation).

Once shoppers use it, it's also a place for a gentle next step: a discount code for the next order or
a Buy again button, below the tracking, never above it.
