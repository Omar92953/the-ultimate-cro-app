# Branding

| Folder | What's in it |
|---|---|
| `app-store/` | What's uploaded to the App Store listing now: the feature image, the 6 screenshots (1600 x 900) and the review screencast. Alt texts: `listing/README.md`. |
| `logos/` | The app icon (1200 x 1200, used in the listing), the favicon, the mark and the wordmark (black and white). |
| `social/` | Profile pictures and wordmarks for social media (`social/README.md`). |
| `listing/` | The design system the listing images are made with: styles, templates, widget crops (`listing/README.md`). Render with `scripts/listing/render.sh`; output goes to `listing/out/` (not in git). |
| `old/` | Earlier listing images and app screenshots, kept for reference. Not uploaded. |
