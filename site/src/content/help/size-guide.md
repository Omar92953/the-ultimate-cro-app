## What shoppers see

Two links by the size picker: **Size chart** and **Size recommendation**. They open a window with the chart (and a switch between cm and inches) and a size finder. The finder asks for height and weight, and for the fit if you allow it, and answers "We recommend M". The answer comes only from the ranges you typed for each size; it is never guessed.

## Set it up

1. In the app open **Section library → Size guide** (Starter plan).
2. Pick a template, then open **Content**. Name the chart, choose the unit your numbers are in, a garment drawing or your own picture, and write a note (how to measure).
3. Add columns (Chest, Waist, Inseam) and a row for each size. Ranges like "86 to 91" work.
4. For the size finder, fill in height (cm) and weight (kg) from and to for each size. Leave them empty to skip a size. With "Ask how they like it to fit" on, Snug moves the answer one size down and Relaxed one size up.
5. Under **Which products** choose all products, or specific products, collections or tags. A product uses the first chart (from the left) that is meant for it. Add a fit note like "Runs large, size down" if you want shoppers to see it with the answer.
6. Click **See it on my store** to check it in the theme editor (only you see the draft), then **Save**.
7. In the theme editor open a product page, **Add block → Size guide**, and save. By default the links jump under the size picker; the block setting "Where the links go" can keep them where you placed it.

## Good to know

- Height and weight are entered in cm and kg in the app; shoppers can answer in inches and pounds.
- If no size fits the numbers, the shopper is asked to check the chart. Widen your ranges so they cover your customers.
- Charts show only on products that match; a product with no matching chart shows nothing.
